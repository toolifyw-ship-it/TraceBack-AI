# 🚀 TraceBack-AI

An advanced, production-ready AI application powered by **Google AI Studio (Gemini API)**, built with TypeScript, Vite, and seamless cloud deployments.

---

## 🌟 Key Features

- **🧠 Google AI Studio Integration:** Harnesses the power of Gemini models for real-time, low-latency AI responses.
- **⚡ High Performance:** Built on top of Vite and TypeScript for optimized bundles and blazing-fast loading speeds.
- **🛡️ Secure Architecture:** Strict security specifications implemented via `security_spec.md` to protect API endpoints and credentials.
- **📅 Smart Subscription Engine:** Built-in logic for automatic 7-day free trial tracking, automatic expiration, and renewal reminders.
- **📱 Fully Responsive UI:** Flawless cross-device compatibility supporting Mobile, Tablet, Laptop, and Ultra-wide monitors.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, TypeScript, Vite
- **Backend / Services:** Node.js (`server.ts`), Firebase (`firebase.ts`)
- **AI Engine:** Google AI Studio (Gemini API)
- **Hosting:** Vercel / GitHub Pages
